# Cartopia — frontend

Frontend React + TypeScript da Cartopia, construído com Vite.

A aplicação transforma mensagens em pequenas aventuras de entrega, com criação de rotas, escolha de couriers e acompanhamento da jornada.

## Comandos

```bash
npm run dev
npm run build
npm run lint
npm test
```

## Estrutura

- `src/pages`: telas de criação, acompanhamento e privacidade.
- `src/components`: componentes de layout, entrega, rastreio e feedback.
- `src/domain`: tipos, couriers e localidades da entrega.
- `src/services`: comunicação com a API e atualização em tempo real.
- `public`: favicon e assets dos couriers.
